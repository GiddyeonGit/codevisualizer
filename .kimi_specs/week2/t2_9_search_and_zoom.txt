## Graph3D: registerZoomToNode implementation

On mount, register a flyToNode implementation via store.registerZoomToNode:

```
flyToNode(nodeId: string): boolean
```

Implementation:
1. Look up the node mesh in meshRefs by nodeId.
2. If not found, return false.
3. Get the mesh's world position (mesh.position.clone()).
4. Animate the camera:
   - Use a ref for animation state (animating, startTime, startPosition, targetPosition).
   - Set refs to start the animation on next frame.
   - In useFrame, if animating:
     - progress = (now - startTime) / FLY_DURATION (800ms).
     - eased = easeInOutCubic(progress).
     - camera.position.lerpVectors(startPos, targetPos, eased).
     - controls.target.lerpVectors(startTarget, targetPos, eased).
     - controls.update().
     - When progress >= 1, stop animating.
5. The target position should place the camera at a distance that frames the node well:
   - For spherical/concentric: ~8 units from node position.
   - For force-directed: scale by node density (default 8).
   - Direction: from node towards global center (node.position.normalize() * -8 + node.position).
6. Return true.

Cleanup: On unmount, call store.registerZoomToNode(null).

Canvas empty-click handling:
- Add onPointerMissed to <Canvas>: calls store.selectNode(null), store.setHoveredNode(null).

## Graph2D: registerZoomToNode implementation

On mount, register a zoomToNode implementation:

```
zoomToNode(nodeId: string): boolean
```

Implementation:
1. Find the node datum from graphData.nodes.
2. If not found, return false.
3. Get the circle's current cx/cy (from the D3 selection or stored positions ref).
4. Transition the zoom transform:
   - svg.transition().duration(600).ease(d3.easeCubicInOut)
     .call(d3.zoom().transform, d3.zoomIdentity
       .translate(width / 2, height / 2)
       .scale(2)
       .translate(-nodeX, -nodeY));
5. This centers the node and zooms in by 2x.
6. Return true.

Cleanup: On unmount, call store.registerZoomToNode(null).
