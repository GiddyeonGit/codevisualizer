## Theme initialization (client/src/main.tsx)

On app startup:
1. Read localStorage key 'codevisualizer-theme'.
2. If exists, set document.documentElement.dataset.theme to the stored value.
3. If not, check prefers-color-scheme media query: window.matchMedia('(prefers-color-scheme: dark)').matches.
4. If dark preference, set data-theme="dark", else "light".
5. Pass initial value to Zustand store's create() call (defaultTheme param).

## Store theme actions

Already defined in interaction-store.ts spec. Ensure toggleTheme and setTheme also:

1. Set the data-theme attribute on document.documentElement.
2. Store selection to localStorage.setItem('codevisualizer-theme', theme).

## ThemeProvider component (client/src/shared/ui/ThemeProvider.tsx)

Optional wrapper component (not strictly needed since data-theme is set on <html>):

```tsx
export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const theme = useInteractionStore(s => s.theme);

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('codevisualizer-theme', theme);
  }, [theme]);

  return <>{children}</>;
}
```

Wrap App.tsx in ThemeProvider.
