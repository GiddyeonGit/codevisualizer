Implementation details:

1. `selectNode(nodeId)`:
   - Sets selectedNodeId. If called with null, deselects.
   - Does NOT move camera (that's controlled by search result clicks).

2. `toggleTraceSource(nodeId)`:
   - If traceSourceId matches nodeId -> deselect (clearTrace).
   - If traceSourceId is null -> set traceSourceId = nodeId.
   - If traceSourceId is different -> runTrace(targetId: nodeId).
   - runTrace is internal: builds adjacency list from graphData, runs Dijkstra, sets tracePath.

3. `runTrace(targetId)` (internal helper, not on store):
   - Builds adjacency list from graphData.edges.
   - Edge weights: isAccessible=true weight=1, isAccessible=false weight=10.
   - Dijkstra from traceSourceId to targetId.
   - If path found: set tracePath = { nodeIds, edgeIds, totalAccessible }.
   - If no path: tracePath stays null, traceSourceId stays set (user can retry).
   - Edge case: source === target -> set tracePath = { nodeIds: [source], edgeIds: [], totalAccessible: true }.

4. `clearTrace()`:
   - Sets traceSourceId = null, tracePath = null.

5. `setViewMode(mode)`:
   - Updates viewMode. Active graph view component checks this via selector.

6. `setLayoutMode(mode)`:
   - Updates layoutMode. Both graph views check this via selector.

7. `toggleTheme()`:
   - Flips between 'dark' and 'light'.
   - Updates colors from the corresponding ThemeColors object.
   - Sets document.documentElement data-theme attribute.
   - Persists to localStorage key 'codevisualizer-theme'.

8. `registerZoomToNode(fn)`:
   - Sets zoomToNode to the callback. Called by active graph view on mount (with its implementation) and on unmount (with null).

9. `reset()`:
   - Clears all state to initial values except theme preference.
   - Called when a new project is dropped.

10. ThemeColors objects:
    - Define DARK_COLORS and LIGHT_COLORS as typed ThemeColors constants in the same file.
    - DARK_COLORS.bg = '#0f0f13', .surface = '#1a1a23', .text = '#e2e8f0', .textSecondary = '#64748b', .border = '#2a2a3a'
    - LIGHT_COLORS.bg = '#f8fafc', .surface = '#ffffff', .text = '#1e293b', .textSecondary = '#64748b', .border = '#e2e8f0'
    - Node colors for both themes should be identical (distinct colors per kind, not brightness-dependent):
      file='#60a5fa', class='#34d399', interface='#f472b6', function='#fbbf24', variable='#a78bfa', enum='#fb923c', type-alias='#2dd4bf'
    - All other color values appropriate per theme (darker/muted for dark, lighter/bright for light).
