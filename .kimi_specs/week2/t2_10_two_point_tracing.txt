## Tracer module (client/src/shared/lib/tracer.ts)

--- EXISTING CONTENT (create file) ---

import type { GraphData, GraphEdge } from '@/shared/api/types';

export interface TraceResult {
  nodeIds: string[];
  edgeIds: string[];
  totalAccessible: boolean;
}

export function runDijkstra(
  graphData: GraphData,
  sourceId: string,
  targetId: string
): TraceResult {
  // 1. Edge case: source === target
  //    Return path: [source], edges: [], totalAccessible: true

  // 2. Build adjacency list from graphData.edges:
  //    Map<string, Array<{ nodeId: string; edgeId: string; weight: number }>>
  //    Weight = 1 if edge.isAccessible === true, weight = 10 if false

  // 3. Dijkstra implementation:
  //    - distances: Map<string, number> (default Infinity)
  //    - previous: Map<string, { nodeId: string; edgeId: string } | null>
  //    - unvisited: Set<string> of all node IDs
  //    - distances.set(sourceId, 0)
  //
  //    While unvisited.size > 0:
  //      current = min-distance node in unvisited
  //      if current === targetId -> break (found shortest path)
  //      if distances.get(current) === Infinity -> break (no path)
  //      unvisited.delete(current)
  //      for each neighbor of current:
  //        alt = distances.get(current) + neighbor.weight
  //        if alt < distances.get(neighbor.nodeId):
  //          distances.set(neighbor.nodeId, alt)
  //          previous.set(neighbor.nodeId, { nodeId: current, edgeId: neighbor.edgeId })

  // 4. Reconstruct path:
  //    If no path found (targetId not in previous) -> return empty path
  //    Walk backwards from targetId through previous map:
  //      nodePath: string[] = []
  //      edgePath: string[] = []
  //      while current !== sourceId:
  //        nodePath.unshift(current)
  //        prev = previous.get(current)
  //        edgePath.unshift(prev.edgeId)
  //        current = prev.nodeId
  //      nodePath.unshift(sourceId)
  //    Check totalAccessible: if any edge in edgePath has isAccessible === false -> false

  // 5. Return { nodeIds: nodePath, edgeIds: edgePath, totalAccessible }
}

--- END EXISTING CONTENT ---

Implementation note: Use a simple array-based priority queue (binary heap optional, not needed for <2000 nodes). A sorted `unvisited: string[]` is fine for this scale.

## Store integration

In interaction-store.ts, add a PRIVATE module-scoped function runTrace (not on the store interface, just a const in the same file):

  runTrace(targetId: string): void
    - Takes graphData and traceSourceId from store.get().
    - If graphData or traceSourceId is null, return (no-op).
    - If traceSourceId === targetId, set tracePath to a single-node path (source==target).
    - Otherwise, call runDijkstra(graphData, traceSourceId, targetId).
    - Set tracePath = result.
    - If no path found (result.nodeIds is empty), traceSourceId stays set (user can Ctrl+click a different node to retry).

Called from toggleTraceSource when traceSourceId is already set and user Ctrl+clicks a different node.

  - opacity = 1.0 (vs 0.3 for non-trace edges).
  - color = '#60a5fa' (bright blue).
  - linewidth = 2 (via linewidth material or mesh-based thick line).

Animated tracer dot in Graph3D:
- A separate component or element inside GraphNodes that renders a small sphere (radius 0.3, emissive yellow #fbbf24).
- Only rendered when tracePath exists (checked via store selector).
- Uses useRef for progress (0 -> 1), increment per useFrame by 0.005.
- On tracePath change (new trace started mid-animation): reset progress to 0 immediate.
- Build a THREE.CatmullRomCurve3 from trace path node positions (look up from meshRefs).
- travelPoint = curve.getPoint(progress).
- Set the sphere's position to travelPoint each frame.
- When progress >= 1, reset to 0 (continuous looping tracer).
- Import CatmullRomCurve3 from 'three' (it's a core export -- no extra dependency).

Animated tracer dot in Graph2D:
- A small SVG circle (r=4, fill='#fbbf24') appended to the SVG group.
- Use requestAnimationFrame ref for progress (same 0->1 cycle, increment 0.005 per frame).
- Interpolate position: find the two consecutive trace nodes bracketing the current progress fraction. Use d3.interpolateObject for the lerp.
- Only rendered when tracePath exists.
- On tracePath change: reset progress to 0.

Canvas empty-click: Calls store.deselectAll() which sets selectedNodeId = null (NOT clearTrace). The trace remains visible.

## Keyboard: isTraceModifier helper

Shared utility function (define locally or in shared/lib):

```
export function isTraceModifier(event: MouseEvent | PointerEvent | React.MouseEvent): boolean {
  return event.metaKey || event.ctrlKey;
}
```

- metaKey = Cmd on macOS.
- ctrlKey = Ctrl on Windows/Linux.
- Used by both Graph3D onClick and Graph2D click handler.

Graph3D click handler:

```
onClick={(e) => {
  e.stopPropagation();
  if (e.nativeEvent.metaKey || e.nativeEvent.ctrlKey) {
    e.nativeEvent.preventDefault();
    store.toggleTraceSource(node.id);
  } else {
    store.selectNode(node.id);
  }
}}
```

Graph2D click handler:

```
circle.on('click', (event: MouseEvent, d: GraphNode) => {
  if (event.metaKey || event.ctrlKey) {
    event.preventDefault();
    store.toggleTraceSource(d.id);
  } else {
    store.selectNode(d.id);
  }
});
```
